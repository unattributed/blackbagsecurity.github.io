# Site Governance

- Operator supplied, verified governed bundles and explicit current owner direction supersede stale historical design reviews.
- Mockup raster dimensions are reference coordinate systems. They do not necessarily define production CSS maximum widths.
- Approved content and composition remain locked unless the owner explicitly reopens them.
- Apply the sitewide desktop readability standards established by MAIN and SERVICES to new pages.
- Preserve the current MAIN and SERVICES production scale, common header, navigation, and footer standards.
- Treat historical review files as historical and subordinate to current governed direction. Keep those files intact.
- Production remains untouched until the owner explicitly authorizes a production change.
